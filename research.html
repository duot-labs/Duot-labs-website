RESEARCH & SYSTEMS

Hard systems infrastructure for HPC & AI.

Duot Labs is an independent research studio building hard systems infrastructure for high-performance computing and artificial intelligence. We focus on hardware-software co-design, memory and caching runtimes, and high-throughput execution engines. Rather than building surface-level applications, our research targets the core computational bottlenecks of modern systems—optimizing memory bandwidth, reducing inference latency, and maximizing hardware utilization from edge robotics to large-scale LLM deployment.

SYSTEMS 01

Hardware-Software Co-Design

Designing unified architectures where compiler passes, custom GPU kernels, and underlying silicon constraints interact directly to maximize FLOP utilization and compute efficiency.

  • ✓ Custom CUDA/Triton kernels for non-standard attention mechanisms and quantized operators
  • ✓ Micro-architectural profiling & hardware performance counter telemetry
  • ✓ Heterogeneous accelerator orchestration across GPU, NPU, and edge hardware
SYSTEMS 02

Memory & Caching Runtimes

Targeting memory bandwidth as the primary bottleneck in modern LLM deployment and high-throughput vector processing through intelligent memory layout and zero-copy runtimes.

  • ✓ KV-cache compression, paging algorithms, and dynamic memory allocation runtimes
  • ✓ Zero-copy payload parsing and shared-memory inter-process communication
  • ✓ High-bandwidth memory (HBM) layout optimization for massive model context windows
SYSTEMS 03

High-Throughput Execution Engines

Building low-overhead, concurrent execution runtimes engineered for deterministic low latency and extreme throughput across distributed compute clusters.

  • ✓ Asynchronous, non-blocking I/O engines for multi-thousand RPS inference streams
  • ✓ P99 tail-latency suppression for real-time scoring and autonomous control loops
  • ✓ Lock-free data structures and vectorized stream processing pipelines
SYSTEMS 04

Edge Robotics to LLM Deployment

Eliminating compute bottlenecks across the full hardware spectrum—from real-time, low-power edge robotics and spatial vision to multi-node LLM serving infrastructure.

  • ✓ Low-latency spatial vision & sensor telemetry runtimes for edge hardware
  • ✓ Distributed tensor & pipeline parallelism for large-scale model serving
  • ✓ High-availability failover, dynamic load balancing, and edge-to-cloud routing
